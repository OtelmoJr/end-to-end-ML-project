# 🚗 Projeto de Data Science - Nova Drive BenQ

## Descrição

Este projeto tem como objetivo prever a inadimplência de clientes da Nova Drive BenQ, empresa que oferece crédito para financiamento de veículos. Os dados estão organizados em um banco relacional contendo informações de clientes, pedidos de crédito, parcelas e seus respectivos status de pagamento.

## Etapas do Projeto

- 🔍 Análise do modelo relacional e consultas SQL para extração de dados
- 📊 Análise exploratória para identificação de inconsistências (valores nulos, outliers, erros de digitação)
- 🧹 Pré-processamento com limpeza, codificação de variáveis categóricas e normalização de variáveis numéricas
- 🤖 Treinamento e avaliação de modelos preditivos supervisionados
- 💾 Salvamento dos artefatos do pipeline (normalizador, codificador, seletor de atributos e modelo)
- 🌐 Criação de uma API para servir o modelo com testes via Streamlit e script Python
- ☁️ Deploy da aplicação na nuvem com AWS EC2

## Organização

O projeto está modularizado em diretórios correspondentes a cada etapa do pipeline, com documentação e scripts separados.
